# Forma GNU/Linux　By.soup1023

Forma GNU/Linuxは、「造形美」をコンセプトとしたDebianベースのLinuxディストリビューションです。
単に使いやすいだけではなく、ユーザーの手で最大限自由に、最大限簡単に「管理・カスタマイズ」できる環境を目指して開発を進めています。

---

## 🎯 特徴

### 📦 必要なものを選び、不要なものは持たない。
Debian には、多くのハードウェアへ対応するために数多くのカーネルモジュール（ドライバー）が含まれています。
Forma GNU/Linuxでは、使用しないドライバーを必要に応じて `tar.xz` 形式でアーカイブし、システム容量を節約できる仕組みを提供する予定です。必要になった場合は、いつでも展開して元に戻せます。
なお、すべてのカーネルモジュールを最初から `*.ko.xz` のような圧縮形式にすることは採用していません。圧縮モジュールは容量を削減できる一方、読み込み時に展開処理が必要となるため、CPU性能が低い環境では起動時間に影響する場合があります。
Forma GNU/Linuxは、容量とパフォーマンスのバランスを重視し、ユーザー自身が選択できる設計を目指しています。

### 🌐 オフラインを考慮した設計
Forma GNU/Linux は、インターネット環境がなくても基本的なセットアップや利用ができるよう設計しています。
また、開発者の悪ふざけにより、なぜかテトリスが収録されています。

### 💾 独自インストーラー
Forma GNU/Linux では、**Forma Installer** と呼ばれる独自の TUI（Text User Interface）インストーラーを採用しています。
GUI インストーラーほど多機能ではありませんが、キーボードだけで直感的に操作できることを目標に開発しています。ディスクの選択やユーザー設定など、基本的なインストール作業を分かりやすく行えるよう設計しています。
なお、Forma Installer は **Python** で開発されています。実行速度だけを考えれば C や Go といった言語の方が適しているかもしれません。しかし、開発効率や保守性、機能追加のしやすさを重視し、現在は Python を採用しています。

### 🧰 独自コマンド
Forma GNU/Linux では、システム管理をより分かりやすく行うために、**`forma`** という独自コマンドを提供します。
`forma` コマンドでは、ドライバーやパッケージ、カーネルモジュール、システム設定など、Forma 独自の機能を一元的に管理できるようにすることを目標としています。
また、コマンドライン操作に慣れていないユーザー向けに、TUI ベースの設定ツール **`forma-tui`** の開発も予定しています。キーボードだけでシステム設定や管理を行える環境を提供し、初心者から上級者まで扱いやすい管理ツールを目指しています。

### 💿 複数のエディション
Forma GNU/Linuxは用途に応じて複数のエディションを用意しています：

| Edition | Description |
| :--- | :--- |
| **Standard Edition** | 一般的なデスクトップ・ノートPC向けの標準構成です。必要なドライバーを厳選し、容量と互換性のバランスを重視しています。 |
| **Desktop Edition** | GUI環境を含むデスクトップ向けエディションです。日常利用を想定しており、現在開発中です。 |
| **Full Edition** | 幅広いハードウェアに対応するため、多数のドライバーや追加コンポーネントを収録したエディションです。サーバーや特殊な環境での利用も想定しています。 |
| **Minimal Edition** | 必要最低限の構成のみを収録した軽量エディションです。一般的なPCでの利用を前提とし、自分で環境を構築したいユーザー向けです。 |
| **Garbage Edition** | 開発者の悪ふざけから生まれた、ただのゴミ。まともな環境を求める人にはおすすめしません。 |

### ✅ システム要件

Forma GNU/Linux のシステム要件は、**BIOS** と **UEFI** の起動方式によって異なります。

### BIOS

| Edition              | Minimum CPU | Recommended CPU | Minimum RAM | Recommended RAM | Minimum Storage | Recommended Storage |
| -------------------- | ----------- | --------------- | ----------- | --------------- | --------------- | ------------------- |
| **Standard Edition** | 1 Core      | 2 Cores+        | 70 MB+      | 128 MB+         | 1 GB+           | 5 GB+               |
| **Desktop Edition**  | 2 Cores+    | 4 Cores+        | 512 MB+     | 1 GB+           | 10 GB+          | 20 GB+              |
| **Full Edition**     | 1 Core      | 2 Cores+        | 128 MB+     | 256 MB+         | 1 GB+           | 5 GB+               |
| **Minimal Edition**  | 1 Core      | 2 Cores+        | 70 MB+      | 128 MB+         | 1 GB+           | 5 GB+               |
| **Garbage Edition**  | 1 Core+     | 1 Core+         | 10 MB+      | 10 MB+          | 1 GB+           | 5 GB+               |

### UEFI

| Edition              | Minimum CPU | Recommended CPU | Minimum RAM | Recommended RAM | Minimum Storage | Recommended Storage |
| -------------------- | ----------- | --------------- | ----------- | --------------- | --------------- | ------------------- |
| **Standard Edition** | 1 Core      | 2 Cores+        | 256 MB+     | 512 MB+         | 1 GB+           | 5 GB+               |
| **Desktop Edition**  | 2 Cores+    | 4 Cores+        | 512 MB+     | 1 GB+           | 10 GB+          | 20 GB+              |
| **Full Edition**     | 1 Core      | 2 Cores+        | 256 MB+     | 512 MB+         | 1 GB+           | 5 GB+               |
| **Minimal Edition**  | 2 Cores     | 2 Cores+        | 256 MB+     | 512 MB+         | 1 GB+           | 5 GB+               |
| **Garbage Edition**  | N/A         | N/A             | N/A         | N/A             | N/A             | N/A                 |

> [!NOTE]
> 現時点では、UEFI 環境で BIOS より多くのメモリを必要とする原因は判明していません。
>
> ただし、UEFI 環境を 256 MB 未満のメモリで運用するケースは非常に少ないため、実用上は大きな問題にならないと考えています。

## 🎯 プロジェクトの目的
Forma GNU/Linux の目的は、最初から全部入りの Linux を作ることではありません。
必要なものを自分で選び、不要なものは持たない。そして、Linux の仕組みをほんの少しでも理解しながら、自分だけの環境を構築できることを大切にしています。
初心者から上級者まで、それぞれの知識や用途に合わせて自由にカスタマイズできるディストリビューションを目指しています。
